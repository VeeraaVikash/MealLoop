Images are layout and copy references (292 pt wide phones, multiply by 1.346 for 393 pt). Orbit backdrop on every frame. Shared with the Door Scanner and not redrawn: role selection (the Kitchen Staff row), the What you do sheet wording (write it for this role), the password page (role chip "Kitchen Staff"), the SOS panel, and the offline screen. Status text in lists is a small dot plus plain text, never a pill.
