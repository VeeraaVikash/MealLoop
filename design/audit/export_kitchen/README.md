# export_kitchen · run KITCHEN · pack v2 (2026-10-19)

68 PNG files at 2× (786 × 1704 px): every Kitchen Staff frame on page 09 after pack v2. Names follow the reference images in `design/reference/kitchen_2026-10/` (K01–K18); a letter suffix marks extra states, and K00 is the What you do sheet (shared with role selection, no reference image). Scrolling pages show the first screen.

The v1 exports (67 files, with the approval-loop pages) are kept unchanged in `archive_v1/` with their README.

How they were made: each frame was cloned above page 09 and scaled 2× (plan in plugin data `mealloop/kt_exp2`). The figma.com asset host is blocked by this session's network policy, so each clone was captured inline (`get_screenshot`, base64) and the saved PNG copied here. The clones were removed afterwards. All data is sample.
