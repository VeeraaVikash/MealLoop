45 PNG files at 2× (786 × 1704 px): every Supervisor frame on page 09. Names follow the reference images in `design/reference/supervisor_2026-10/` (S00–S19); a letter suffix marks extra states.

How they were made: each frame was cloned above page 09 and scaled 2× (plan in plugin data `mealloop/sv_exp`). The figma.com asset host is blocked by this session's network policy, so each clone was captured inline (`get_screenshot`, base64) and the saved PNG copied here. The clones were removed afterwards.
