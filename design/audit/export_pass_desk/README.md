# export_pass_desk · run PASS-DESK (2026-10-17)

47 PNG files at 2× (786 × 1704 px): every new Pass Desk frame on page 09 (46) and the changed Kitchen Staff Alerts (MS-E1). Names follow the reference images in `design/reference/pass_desk_2026-10/` (P01–P17) with a suffix per state; `PD_` files have no reference image.

How they were made: each frame was cloned 8000 pt above itself and scaled 2× (plan in plugin data `mealloop/pd_export_plan`). The figma.com asset host is blocked by this session's network policy, so each clone was captured inline (`get_screenshot`, base64) and the saved PNG copied here. The clones were removed afterwards. Codes and colours in the frames are sample values.
