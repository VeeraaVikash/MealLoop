# Exports (brand audit D1, 2026-10-08)

27 key screens at scale 2 (phone frames 786 × 1704; the A4 report page 1190 × 1684; the brand sheet 3360 × 9172). All data on these screens is sample. Student screens come from 04 Student Light (the source).

**How they were made:** the screenshot service renders a node at its natural size only, and its download host is blocked in this environment. Each screen was therefore rendered from a temporary 2× clone of the frame, saved, and the 26 clones were removed in the same stage (snapshot st240 = st239). Each clone's PNG is within 0.3% of the byte size of Figma's own 2× export of the original; the difference is anti-aliasing only.
