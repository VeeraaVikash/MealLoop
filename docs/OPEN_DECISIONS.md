# Open decisions

This file has three parts: **Resolved** (behaviour that is approved, with its source), **Open** (decisions still to be made, split into Product and Technical), and **Conflicts** (places where an existing document disagrees with [`PRD.md`](PRD.md)). Where a gap number exists in `design/audit/prototype_gaps.md` it is given.

For the open decisions, each row gives the options and a suggested default so work can continue; **a suggested default is not a decision.** For decisions that belong to the owner or to SRM, the suggested default is "none" and nothing should be built on a guess.

"Approved" in the Resolved table means stated as approved in an active repository specification or by the owner in the PRD task prompt. A policy number, reward value, threshold or anything that depends on SRM is never listed as resolved.
